# Project Statement

## Problem Statement
Managing books manually can be difficult and time-consuming. The Library Management System provides a simple way to add, search, issue, return, display, and delete books using a Java-based console application.

## Scope of the Project
The project focuses on basic book management using Java. Book records are stored temporarily using an ArrayList during program execution.

## Target Users
- Librarians
- Library staff
- Students
- Beginners learning Java and OOP

## High-Level Features
- Add new books
- Display all books
- Search books by title
- Issue books
- Return books
- Delete books
- Automatic Book ID generation
- Basic input validation
